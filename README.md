# sapper

Классический «Сапёр» — консольная игра на Python (без зависимостей, нужен только Python 3).

## Требования

- Python 3.8+ (стандартная библиотека, ничего ставить не нужно)
- Терминал с поддержкой ANSI (macOS/Linux — любой; Windows — Windows Terminal или PowerShell)

## Запуск

```bash
git clone https://github.com/Alikyshkin/sapper.git
cd sapper
python3 main.py
```

На Windows:

```powershell
py main.py
```

## Правила

- Открой все клетки без бомб — победа. Открыл бомбу — проигрыш.
- Число в клетке — сколько бомб в 8 соседних клетках.
- Первый ход всегда безопасен: бомбы расставляются после него, в стороне от выбранной клетки.

## Управление

| Ввод | Действие |
|---|---|
| `x y` (например `3 5`) | открыть клетку |
| `f x y` (например `f 3 5`) | поставить/снять флаг |
| `q` | выйти |

Координаты: `x` — столбец, `y` — строка, отсчёт с нуля (подписаны на поле).

## Сложность

| Уровень | Поле | Бомбы |
|---|---|---|
| 1 — Лёгкий | 8×8 | 9 |
| 2 — Средний | 12×12 | 22 |
| 3 — Сложный | 16×16 | 40 |

## Обозначения

- `#` — закрытая клетка
- `.` — открытая пустая клетка
- `1`–`8` — количество бомб рядом
- `F` — флаг
- `*` — бомба (видна после конца игры)
