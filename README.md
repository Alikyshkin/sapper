# Сапёр

Классический «Сапёр». [Играть в браузере](https://alikyshkin.github.io/sapper/).

В браузере доступны три уровня. Нажмите на клетку, чтобы открыть её. Правая кнопка мыши или клавиша `F` ставит или снимает флаг. На сенсорном экране выберите действие «Открыть» или «Флаг» над полем. Стрелки перемещают фокус, Enter и пробел выполняют выбранное действие.

Для локального запуска браузерной версии выполните `python3 -m http.server 8000` в папке проекта и откройте `http://localhost:8000/`.

## Консольная версия

Игра на Python, внешние зависимости не нужны.

## Требования

- Python 3.8+ (стандартная библиотека, ничего ставить не нужно)
- ANSI-терминал позволяет подсвечивать клетки. В простом терминале и при перенаправлении вывода поле читается без цветов

## Запуск

```bash
git clone https://github.com/Alikyshkin/sapper.git
cd sapper
python3 main.py
```

На Windows:

```powershell
py main.py
```

## Правила

- Открой все клетки без бомб — победа. Открыл бомбу — проигрыш.
- Число в клетке — сколько бомб в 8 соседних клетках.
- Первый ход всегда безопасен: бомбы расставляются после него, в стороне от выбранной клетки.

## Управление

| Ввод | Действие |
|---|---|
| `x y` (например `3 5`) | открыть клетку |
| `f x y` (например `f 3 5`) | поставить/снять флаг |
| `q` | выйти |

Координаты: `x` — столбец, `y` — строка, отсчёт с нуля (подписаны на поле).

## Сложность

| Уровень | Поле | Бомбы |
|---|---|---|
| 1 — Лёгкий | 8×8 | 9 |
| 2 — Средний | 12×12 | 22 |
| 3 — Сложный | 16×16 | 40 |

## Обозначения

- `#` — закрытая клетка
- `.` — открытая пустая клетка
- `1`–`8` — количество бомб рядом
- `F` — флаг
- `*` — мина после окончания игры
- `X` — мина, на которой закончилась партия
- `!` — ошибочный флаг на итоговом поле

Вывод без цветов: `NO_COLOR=1 python3 main.py` в macOS или Linux.
